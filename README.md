📊 Tableau Workbook: Global Superstore Analysis
This repository contains a Tableau workbook (PRACTICAL SKILL 2.twb) that provides a comprehensive and interactive analysis of sales data from the Global Superstore 2016 dataset. The project serves as a practical example of business intelligence and data visualization, exploring key metrics and trends to derive actionable insights.

Key Features and Analyses
The workbook is designed to answer critical business questions and visualize performance across various dimensions. It includes several sheets and a central dashboard to showcase:

Overall Sales & Profit Performance: Visualizations of total sales and profit over time.

Regional Performance: Analysis of sales and profit by geographic region and market.

Product Insights: Breakdown of sales by product category and sub-category to identify top-performing and under-performing products.

Customer Segmentation: Metrics related to different customer segments.

Shipping and Logistics Analysis: Custom calculations to measure shipping time and efficiency.

Data Source
The analysis is powered by the global_superstore_2016.xlsx Excel file. The primary data source used within the workbook is the Orders sheet from this file

How to Use
To open and interact with this workbook, you will need Tableau Desktop or Tableau Public.

Clone or download this repository to your local machine.

Open the PRACTICAL SKILL 2.twb file with Tableau.

Ensure the global_superstore_2016.xlsx file is in the same directory as the workbook or update the data source connection if prompted.

The workbook is designed to be self-contained and ready to explore.

Calculated Fields
The workbook includes two custom calculated fields to enhance the analysis:

Shipping time: A calculation measuring the duration between the Order Date and the Ship Date.

Order date shift date: An alternative calculation to achieve the same metric.
